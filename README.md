# AgriLink

AgriLink is a smart farming platform that helps farmers make better decisions about their crops and markets.

## Features

- 🌱 Crop Quality Scanner
- 📊 Market Recommendations
- 🚚 Shared Transport Logistics
- 🛒 Buyer Marketplace
- 💰 Earnings Forecast

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```
